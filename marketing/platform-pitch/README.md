# عرض منصة الشنتف — Platform Pitch

إعادة إنتاج شاملة لـ `عرض منصة الشنتف للاستثمار العقاري v1.mp4` مع **كل تفاصيل المنصة الحالية**.

## المخرجات
- `عرض منصة الشنتف للاستثمار العقاري v2.mp4` — 16:9 (1920×1080)
- `عرض منصة الشنتف للاستثمار العقاري v2-9x16.mp4` — 9:16 موبايل (1080×1920)
- نسختان في `~/Downloads` · ~4–5 دقائق · عربي · ثيم الغابة/الذهبي

## ما يغطيه الفيديو
1. عنوان المنصة والهوية (25+ سنة / 200+ مشروع)
2. مسارات «ماذا تريد؟»
3. الفرص المميزة والشارات
4. كل العروض والفلاتر
5. تفاصيل العرض (خريطة · تنظيم · سعر · واتساب)
6. مقارنة عرضين
7. رحلة الاستثمار
8. فحص الأرض (خاص، بدون نشر) + طوبوغرافيا
9. طلب النشر والوسائط ورمز التتبع
10. التتبع وبوابة عرضي + SMS
11. الخدمات والروابط الحكومية
12. سوق الأراضي
13. مساعد الشنتف
14. التواصل والختام

## إعادة التسجيل
```bash
cd marketing/platform-pitch
# سطح المكتب 16:9
node record_pitch.mjs
# موبايل / ريلز / ستوريز 9:16
RATIO=9x16 node record_pitch.mjs
```

المصادر: `shots/` · `shots-mobile/` · المشاهد: `scene.html` + `chapters.js`
